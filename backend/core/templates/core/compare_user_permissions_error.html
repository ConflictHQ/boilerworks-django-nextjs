How to Use the Permission Comparison Tool

  1. Navigate to the Django Admin → Users page
  2. Select 2 or more users using the checkboxes on the left
  3. Choose "Compare user group permissions" from the Actions dropdown at the top
  4. Click the "Go" button
  5. You'll be redirected to the comparison page where you can select a base user
